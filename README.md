# 《六祖大師法寶壇經》閱讀與研讀導航器

**版本**：宗寶編，CBETA 大正藏 **T48n2008**（大正新脩大藏經第 48 冊，No. 2008）。

這個專為 iPhone 與桌面電腦設計的互動經文讀本，包含宗寶本全卷轉寫、卷首目錄與序贊、十品正文、六篇附錄；並提供段落跳轉、全文檢索、收藏書籤、記錄閱讀進度、3 種色彩主題、可調字體和行距、研讀主題索引，以及**20 條選段白話語譯及註釋**、章節導讀。

## 立即使用：獨立 HTML（免網絡）

直接開啟 `index.html`。所有經文、導讀、搜尋所需資料、CSS、JavaScript 已經內嵌；閱讀時無須連線或伺服器，不會呼叫第三方 API。

**iPhone 注意**：iOS「檔案」中的 HTML 快速預覽可能不執行 JavaScript。如果按鈕無法操作，建議使用下述 GitHub Pages 方式以 Safari 開啟，然後點「分享」→「加入主畫面」。

## GitHub Pages：部署流程

1. 在 GitHub 建立一個 repository（例如 `tanjing-reader`）。
2. 將本套件根目錄內的 `index.html`、`README.md`、`SOURCE_AND_LICENSE.md` 和 `source/` 文件夾上傳到該 repository 的根目錄。**`index.html` 必須放根目錄**，而非壓縮包內的上層資料夾。
3. 在該 repository 的 **Settings → Pages** 中選取 **Deploy from a branch**，Branch 選 `main`，目錄選 `/ (root)`，按 **Save**。
4. 等待 GitHub Pages 顯示部署成功，再按 **Visit site**。
5. 在 iPhone Safari 開啟網站，若希望像 App 使用，可選「分享 → 加入主畫面」。

網站無伺服器端資料庫。**書籤、字體、主題及閱讀位置只保存在當前瀏覽器的 localStorage**：換機、換網域或清除資料後不會自動同步。可在「我的書籤」匯出 JSON 供個人備份（目前不提供匯入功能）。

## 經文與導讀的邊界

- 經文取自 **Kanripo KR6q0083 所收的 CBETA T48n2008 轉寫**；提供全文閱讀層、完整嵌入轉寫視圖，另在 `source/KR6q0083_001.txt` 保存可核對的轉寫。
- 文字原始的標點、異文夾註等**不是編寫者重新校訂**；為便於閱讀，界面將轉寫用控制標記（例如 `¶`、`<pb:...>`）轉為呈現層或隱藏，並依轉寫內容作顯示分段。這不等於重新出版 CBETA 的完整學術校勘版本。
- **章首摘要、白話選譯、詮釋、思考題、主題索引均為額外編輯文字**；不等同 CBETA 原注、也不是全書逐句白話翻譯。別把其判斷當作史實或經文本身。可用「來源」查看原始轉寫。
- 若做精確校勘或引用，請回到 CBETA 原版比對行號、頁欄、異文及版次。
- 使用者所供 `jnbooks` 2016 HTML 網址未能由建立流程直接讀取。因此本讀本**沒有宣稱與該特定網頁逐字逐註完全一致**。已核實使用同一部宗寶編 T48n2008 的 Kanripo 轉寫來源。
